# 🌐 Frontend - TBAlert
***
This is the TBAlert frontend application built with React

![img.png](img.png)
---

## 🚀 Tech Stack

- **Framework**: React (with TypeScript support)
- **Styling**: Material UI
- **State Management**: Redux
- **Authentication and Authorization**: Keycloak
- **API calls**: Axios

---

## ⚙️ Installation

```bash
# Clone the repository
git clone https://github.com/Nzarite/tb-alert-frontend.git

# Navigate into the directory
cd tb-alert-frontend

# Install the dependencies
npm install
```

## 🏃‍♂️ Running the Application
```bash
# Run the application in development mode
npm run dev
```

The application will be up and running at http://localhost:5173
